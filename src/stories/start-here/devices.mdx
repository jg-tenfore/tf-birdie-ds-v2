  Clubs run Birdie on a counter terminal at the pro shop and on handhelds out on the course and in the dining room. The prototypes and Storybook can show any screen on any of them. Only each device's <strong>aspect ratio</strong> matters here: the design keeps its own density everywhere, dense 12–14px controls on a terminal and MD3 touch sizing on a handheld, so a device is simulated as the CSS viewport its browser actually lays out at.
</Banner>

<P>
  Terminals render at 1×. The handhelds are XHDPI Android screens, so a 720-pixel-wide panel lays out as a 360px CSS viewport at 2×. The two <strong>design canvases</strong> are the frames every screen was drawn on before devices existed (1366×840 for the tablet, 402×797 for the phone); they stay in the list so a screen can still be compared with the size it was designed at. Every profile lives in <Code>src/pos/devices.ts</Code>, the one file the prototype, Storybook's toolbar and this page all read.
</P>
